# 1.5 เครื่องมือและอุปกรณ์ที่ใช้ในการดำเนินงาน

ในการดำเนินโครงงาน ได้มีการเลือกใช้เครื่องมือและเทคโนโลยีต่างๆ ดังนี้:

### ฮาร์ดแวร์ (Hardware)
- เครื่องคอมพิวเตอร์แม่ข่าย (Server) และคอมพิวเตอร์สำหรับพัฒนา
- สมาร์ทโฟนสำหรับการทดสอบระบบแจ้งซ่อม สแกน QR Code และถ่ายภาพหน้างานจริง

### ซอฟต์แวร์และเทคโนโลยี (Software & Technologies)
- **Frontend:** React.js หรือ Angular (สไตล์ Responsive UI สะดวกสำหรับทั้งมือถือและเดสก์ท็อป)
- **Backend:** Python (FastAPI / Flask) หรือ Node.js
- **Database:** PostgreSQL (สำหรับเก็บข้อมูลเชิงสัมพันธ์เช่น ข้อมูลอาคาร, อุปกรณ์, และรายการซ่อม)
- **AI/Machine Learning Tools:** PyTorch / TensorFlow (สำหรับเทรนโมเดลจำแนกอุปกรณ์ชำรุด) และไลบรารีสแกนและประมวลผลข้อความเพื่อประเมินความรุนแรง
- **Map Integration:** Google Maps API หรือ OpenStreetMap สำหรับปักหมุดตำแหน่งอุปกรณ์ชำรุด
